# WinGo Educational SEO Lab

An educational website project for learning probability, randomness, technical SEO, search indexing, and engagement measurement through practical implementation.

## Current status

Phase 1 research and architecture are documented. Website implementation starts in Phase 2; no runnable application or deployment exists yet.

The authoritative project specification is [handoff.txt](handoff.txt).

Read the [Phase 1 report](docs/phase-1-report.md) for decisions, evidence, limitations, and the next build steps. The [documentation index](docs/README.md) links the keyword research, content plan, architecture, simulation model, and validation plan.

## Planned stack

- Astro and TypeScript with static site generation
- Minimal browser JavaScript for educational tools
- Cloudflare hosting
- Configurable Google Analytics 4 and Google Search Console setup

## Execution phases

1. Research and architecture
2. Core website and educational content
3. Interactive educational tools
4. Technical SEO
5. Analytics and measurement setup
6. QA and authorized production deployment
7. Post-deployment baseline and monitoring over the first 30 days

Each phase ends with relevant validation, a brief learning recap, and a Git commit and push. Runnable previews and automated checks will be added as implementation progresses.

## Educational boundaries

This project will use local simulations and explicitly stated mathematical assumptions. It does not offer real-money gambling, operator referrals, or predictions of external results.

## Development

Install, build, and test commands will be documented when the application is scaffolded in Phase 2. No runnable application or deployment is included in the research phase.
