## After publication

1. Verify `https://dmplay.kalam.trade/dmplay-wingo-guide/` returns 200, has its own canonical, and has no `noindex` in either HTML or HTTP headers. Check both reference images load.
2. Verify the homepage title is `WinGo Rules, Colors & Probability Guides | Kalam` and the indexable sitemap has 15 distinct URLs, including the new guide.
3. In the existing verified Search Console property, use URL Inspection for the guide. Select **Test live URL**, review eligibility, then **Request indexing** if eligible. Do the same once for the changed homepage if appropriate.
4. Check **Sitemaps** for `https://dmplay.kalam.trade/sitemap.xml`. Submit it if it is not already registered; repeated submissions do not improve ranking.

An indexing request is not a guarantee of inclusion or ranking. This document is a checklist, not evidence that a submission has happened.
